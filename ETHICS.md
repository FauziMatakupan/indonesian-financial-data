# Ethics

This project publishes a small sample of **company-level** financial data that IDX already
publishes publicly. It contains no personal data: no names of individuals, no contact
details, no shareholder identities.

Rules followed:

1. **Public source only.** No login, no paywall, no private endpoint.
2. **Company data, not people.** Financial statements of listed issuers are public by
   design; this repository does not add anything personal to them.
3. **Honest limitations.** Unaudited basis, preliminary years, and trailing year are stated
   in the README, the dataset notes, and the product listing.
4. **No advice.** The data is descriptive. It is not a recommendation to buy or sell any
   security.
5. **Correction over promotion.** If a figure is wrong, it is corrected and the correction
   is noted; the sample is not tuned to look better than the source.
6. **Attribution.** IDX is named as the source everywhere the data is described.
